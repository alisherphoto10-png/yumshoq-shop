# Бренд-гайд

Сюда кладём цветовую палитру, названия шрифтов и другие правила стиля —
чтобы бот, Mini App и маркетинговые материалы не расходились по оформлению.

## Смысловое ядро бренда

`brand-core.md` — словесная основа бренда: смысл имени, легенда, позиционирование,
миссия, ценности, архитектура линеек (Care/Gift/Mini), тон коммуникации — на
основе оригинального позиционирования основателя и реального логотипа. Пишем
тексты для бота, карточек товаров и соцсетей на основе этого файла, а не с нуля.

## Цвета (черновой список, см. `brand-core.md` §7 для источников)

| Роль | HEX |
|---|---|
| Основной (Yumshoq Sand, из логотипа) | `#B7A091` |
| Хлопковый белый (фон) | `#FAF6F1` |
| Тёплый молочный (нейтраль) | `#F1E7D8` |

Это цвета бренда/упаковки — светлые тёплые нейтрали. У фотоконтента в соцсетях
свой (тёмный, текстурный) фон — см. `brand-core.md`, не смешивать эти два
слоя. Точные hex-коды стоит сверить с оригинальным цветовым блоком в Canva,
если он существует отдельно от текстового описания.

**Не решено:** в `design/customer-mockup.html` используется другая палитра
(тёмный фон + фиолетовый `#8b5cf6`) — не совпадает с песочной палитрой бренда.
Нужно решение, приводить ли Mini App к бренд-палитре.
