# Бренд-гайд

Сюда кладём цветовую палитру, названия шрифтов и другие правила стиля —
чтобы бот, Mini App и маркетинговые материалы не расходились по оформлению.

## Смысловое ядро бренда

`brand-core.md` — словесная основа бренда: ключевая идея, символ, слоган,
позиционирование, манифест, портреты аудитории и tone of voice. Пишем тексты
для бота, карточек товаров и соцсетей на основе этого файла, а не с нуля.

Визуальная часть (палитра, шрифты) пока не задокументирована отдельно — де-факто
уже используется в `design/customer-mockup.html` (тёмный фон, фиолетовый акцент
`#8b5cf6`); формализуем её здесь на следующем шаге, вместе с логотипом.
