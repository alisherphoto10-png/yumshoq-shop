# Логотип

Сюда кладём логотип магазина:
- SVG — основной, векторный вариант
- PNG — растровые копии для превью/аватара бота
- favicon (квадратный, для Mini App)

## Что уже есть

`yumshoq-wordmark-vertical.png` — реальный леттеринг «YUMSHOQ», вертикальный
лок-ап (читается снизу вверх), цвет `#B7A091`, прозрачный фон. Подробное
описание — в `../brand/brand-core.md` §6.

**Не хватает:**
- Векторной (SVG) версии — если есть в Canva, добавить сюда.
- Квадратного/компактного варианта для favicon и аватара бота — вертикальный
  лок-ап для этого не подходит впритык, нужна отдельная компоновка (например,
  вырастить отдельный значок из перечёркнутой буквы Q — см. brand-core.md).
