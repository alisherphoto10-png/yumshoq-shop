# YUMSHOQ SHOP

Telegram-бот магазина натурального мыла ручной работы.

Код бота пишется и деплоится напрямую на сервере (через Claude Code, запущенный там же).
Этот репозиторий используется как канал доставки не-текстовых файлов — того, что нельзя
передать текстовым запросом: логотип, шрифты, фото товаров, брендовые материалы.

## Структура

```
assets/
  logo/      — логотип (SVG + PNG, favicon)
  fonts/     — брендовые шрифты (.woff2 / .ttf)
  products/  — реальные фото товаров
  brand/     — цветовая палитра, гайд по стилю
```

Файлы отсюда попадают на сервер через `git pull` в папке проекта.
