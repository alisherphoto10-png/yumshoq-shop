`customer-mockup.html` — кликабельный статичный макет покупательской части Mini App
(тёмная тема, фиолетовый акцент): Главная, Каталог, Товар, Корзина, Оформление заказа,
Спасибо за заказ, Мои заказы, Заказ, Профиль, Избранное.

Товары и заказы внутри — хардкод в JS-массивах (для наглядности макета).
При переносе в реальное приложение: заменить эти массивы на запросы к API
(`GET /api/products`, `GET /api/cart`, `GET /api/orders` и т.д.), сохранив разметку и стили.

**Внимание:** цветовая палитра этого макета (тёмный фон + фиолетовый `#8b5cf6`)
не совпадает с песочной палитрой бренда, описанной в `../assets/brand/brand-core.md`.
